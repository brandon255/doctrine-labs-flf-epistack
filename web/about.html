The thesis, in plain language

AI should strengthen the human, not replace them. A tool that absorbs cognitive overhead and points you back at what makes you human — judgment, relationships, generosity — is more valuable than one that optimizes you for throughput.

Three principles make that real in code: data stays local, writes go through human gates, and every claim the system makes carries an honest label (PROVED / BUILT / HYPOTHESIS / PLANNED). No quiet cloud calls, no rubber-stamp approvals, no aspirational claims dressed as facts.

What's already built (the larger system)

Every claim below is labeled honestly. "Built" means it runs today in the master repo.

Built Integrity ledger. Hash-chained audit trail. If any stored claim is edited, the chain breaks visibly.
Built Human approval gates. Writes require an Approve token + a one-sentence "why." Stops rubber-stamping in code, not in prose.
Built Vault pipeline. Redact → confidence-label → encrypt → write → integrity-check, at the write boundary.
Built Local LLM adapter. Provider-agnostic OpenAI-compat client. Refuses non-local endpoints by default (require_local: true).
Built Provenance genealogy layer. The thing you just opened. Counts distinct source roots behind a pile of evidence blocks.
Built Core OS runtime. Zero runtime npm deps. Node ≥20. Local server on 127.0.0.1. 451+ tests.

What's in progress

Planned Autonomous alias proposal at scale. The FLF slice lets a human accept model-proposed aliases one at a time. The larger system proposes them continuously and learns from accept/reject patterns.
Planned Career OS. A hosted SaaS cartridge — resume, portfolio, interview simulator — on the same chassis. Separate product, separate buyer.
Hypothesis Local-first beats token-metered cloud AI for the user. Flat pricing ($199/yr), unlimited local inference, governance in code. Untested as a business, but the wedge is clear.

What this is not

It is not a productivity app. It does not promise to make you faster. It is a reconnection tool — it absorbs cognitive overhead so you get capacity back, then points you at what makes you human. North star: learning how to be a good person again.

It is also not a model. We do not train LLMs. We build guardrails, orchestration, and a vault around local or hosted models. The intelligence is rented; the judgment is yours.
