Adjudicated assessment

Pick a question. The model proposes an answer with cited work, every citation is checked against the corpus mechanically, and a second model that cannot see the reasoning argues against the conclusion. You decide what stands.

Ask this case a question

The model answers only from the evidence in this case. If the answer isn't here, it says so. It will not invent sources or claims.

Suggest hidden correlations

The model looks at the evidence and proposes pairs that might trace to the same root even though they have different IDs. Every proposal is a suggestion — nothing is written until you click Accept.

Chat and alias-proposal features use a local LLM. Install Ollama and run ollama pull llama3.1, then refresh this page. The tool works fully without it — the static case view above is the gift.
