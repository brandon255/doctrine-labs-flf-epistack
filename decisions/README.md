# Decisions

Your recorded positions on adjudicated conclusions land here, one JSON file per
decision, written by stage 4 of the adjudication protocol.

Nothing in this folder is generated by a model. Each file is a person saying what
they concluded and why, stored next to the machine's reasoning rather than mixed
into it.

## Why this folder exists at all

Stage 4 used to set a variable in the browser and print "on the record." Nothing was
written, so the claim was false. Either the sentence had to go or the persistence had
to be real. We chose real.

## Why it is git-ignored

These are your judgments, not source. A repo you cloned should not carry your
positions back upstream, and the evidence corpus stays untouched either way — the
whole protocol is built so that judging something and changing it are separate acts.

Delete anything here freely. Nothing else reads it.

## What a file contains

```json
{
  "case": "covid",
  "job": "lineage",
  "decision": "accepted",
  "verdict": "verified_with_caveat",
  "independence_grade": "strong",
  "conclusion": "...what the model concluded...",
  "human_position": {
    "assumption": "accept",
    "strongest_objection": "C3",
    "what_would_change_my_mind": "...your words, if you wrote any..."
  },
  "recorded_at": "2026-08-03T04:12:00.000Z"
}
```

`independence_grade` reaches `strong` only when a human position is recorded, because
you are the one lineage on the panel that is not another instance of the thing being
checked. See `docs/A1_CHALLENGER_INDEPENDENCE.md`.
